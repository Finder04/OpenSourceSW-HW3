## GitHub Collaboration Workflow

In this assignment, I practiced the basic GitHub collaboration workflow.

The steps I practiced are:

1. Accept the GitHub invitation.
2. Open the shared GitHub repository.
3. Clone the repository to my computer.
4. Switch to the assigned branch.
5. Pull the latest changes before editing.
6. Create my own submission file.
7. Add and commit my changes.
8. Pull again before pushing.
9. Push my work to the shared branch.
10. Check my submission on GitHub.
